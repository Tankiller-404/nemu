## 关键实现

访存链为逻辑地址→段隐藏基址加偏移→线性地址→TLB/页表→物理地址→L1→L2→DRAM。
ModR/M只按实际基址寄存器选择段：ESP/EBP基址用SS，其余用DS；仅作为SIB索引的EBP不触发SS。
取指用CS，栈读写和bt用SS，普通数据和表达式解引用用DS，字符串目的用ES。
选择符更新时读取GDT并缓存base/limit，不在每次访存时重新读取描述符。

分页以CR0.PE和PG同时开启为条件。CR3指向物理页目录，PDE/PTE通过物理接口读出，
避免递归翻译。不存在的表项用Assert终止执行；page命令使用非致命查询接口。
跨页访问分别翻译两页，再按小端顺序拼接，允许两页映射到不连续物理页。
按指导书不实现完整权限检查、异常投递、LDT、交换和PA4设备/中断。

内核链接0xc0100000但入口二进制仍加载到物理0x100000；启动代码已有va_to_pa处理。
用户程序链接0x08048000。Loader对每个PT_LOAD调用mm_malloc建立映射，
通过返回物理地址的内核高地址别名加载文件数据和清零BSS。用户栈仍由框架分配1MB。
显存测试调用从HAS_DEVICE条件移到IA32_PAGE条件，分页启动即执行写入、读回、清屏。

L2采用非强制包含结构：L2替换不强制清除L1。由于L1无脏数据且每次写同步L2，
L2驱逐时写回后L1副本仍正确；后续L1写命中若L2缺失会重新分配并更新。
cache命令显示各级命中/缺失及h*2+m*200的教学用L1周期估算，不代表真实硬件总周期。

## 复现

在容器内工程根目录执行：

```sh
make clean-nemu clean-testcase clean-kernel
make git_commit= nemu testcase kernel entry
bash tests/pa3-regression.sh
gcc -std=gnu99 -O2 -Wall -Werror -Inemu/include tests/pa3-memory.c nemu/src/memory/memory.c nemu/src/memory/cache.c nemu/src/cpu/exec/system.c nemu/src/cpu/decode/modrm.c -o /tmp/pa3-memory
/tmp/pa3-memory
```

Release重建将全局CFLAGS设为`-MMD -Wall -Werror -c -DNEMU_RELEASE`。
原test.sh未修改；Makefile仅按指导书改内核和用户链接地址。
官方测试附件只覆盖stage1；本工程另外在分段和完整分页环境分别执行同30例。
独立测试覆盖12万次随机操作及8MB全量回读、L2脏块驱逐、跨块和跨非连续页、
未映射页、实际MOV CR3指令处理器冲刷TLB、非零段基址及隐藏描述符刷新。
测试结果证明本地行为，不代表远程评测平台已给出成绩。

## 思考题要点

1. GDT：13位索引最多8192项，每项8字节，最多64KB；第0项为约定的空描述符。
2. GDTR必须用线性地址，否则读取描述符本身又依赖分段，产生循环；分页开启后该线性地址仍须分页。
3. 隐藏描述符缓存保存base/limit等，段选择符装载时更新，消除重复GDT访存。
4. 分段需要连续可变长分配，产生外碎片，扩展和交换困难；编译器的平坦指针假设也限制独立改变段基址。
5. 分页允许非连续物理分配，便于隔离、共享、按需加载和换页；代价为页表和转换开销、内部碎片。
6. 页框按4KB对齐，低12位恒零，20位足以记录32位物理页框；页表基址用物理地址防止递归翻译。
   单级页表对4GB空间需约4MB/进程，二级结构能省去未使用地址区域的页表。
7. 空指针是语言约定的无效指针表示。该平台解引用0会尝试地址转换；通常零页未映射而失败，
   并非CPU认识“空”这个概念。C语言层面的空指针解引用本身为未定义行为。
8. 扁平分段下依靠页级U/S、R/W和CPU特权级保护内核；普通进程不能修改控制寄存器等特权状态。
9. init_page把[0,128MB)及[0xc0000000,0xc8000000)都映射至物理[0,128MB)。
   用户目录保留高地址内核映射，另外创建用户程序、栈、显存映射。
10. 参考C循环pframe_addr是无符号数，`>=0`恒真，减到0之后下溢，导致越界；应使用有界计数或有符号变量。
11. 开分页前全局符号为链接高地址，直接使用无法访问物理RAM；栈上局部变量仍使用当前物理ESP。
    init_page使用全局数组先经va_to_pa；相对CALL/JMP在代码整体平移后位移不变，故低地址执行也能调用init_page。
    恒等映射保证开PG瞬间的低EIP和栈仍可访问，高地址映射保证后续进入链接地址。
    ESP不加KOFFSET会在切换用户页目录后丢失低地址栈映射；普通相对调用init_cond会继续留在低地址代码别名，
    而间接跳转使用符号的绝对高地址，保证内核此后执行位置不依赖被移除的低地址映射。

分段非平坦栈实验：局部变量取地址常由LEA生成栈偏移，指针经DS解引用时假定DS和SS基址相同。
两者基址不同会把同一偏移解释到不同线性地址，破坏编译器ABI假设，导致断言失败。
